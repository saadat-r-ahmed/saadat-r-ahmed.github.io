# CSE330 - Numerical Methods

## Course Overview
This course covers mathematical foundations and computational techniques for solving numerical problems in computer science and engineering. Students learn to implement and analyze numerical algorithms for various mathematical problems.

## Course Topics
- **Numerical Error Analysis**: Understanding floating-point arithmetic and error propagation
- **Root Finding**: Bisection method, Newton-Raphson method, Secant method
- **Linear Systems**: Gaussian elimination, LU decomposition, iterative methods
- **Interpolation**: Lagrange polynomials, Newton's divided differences, spline interpolation
- **Numerical Integration**: Trapezoidal rule, Simpson's rule, Gaussian quadrature
- **Differential Equations**: Euler's method, Runge-Kutta methods
- **Matrix Eigenvalues**: Power method, QR algorithm

## Learning Outcomes
By the end of this course, students will be able to:
- Understand the sources and propagation of numerical errors
- Implement numerical algorithms for solving mathematical problems
- Analyze the accuracy and efficiency of numerical methods
- Apply appropriate numerical techniques to real-world problems
- Use computational tools for numerical analysis
